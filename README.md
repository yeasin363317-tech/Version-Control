
# গাজীরচট মদিনাতুল উলুম ফাজিল মাদ্রাসা — ওয়েবসাইট

এই ডকুমেন্টটা লেখা হয়েছে যাতে **কোডিং না জানা কেউও** বুঝতে পারে কোথায় কী আছে — কোনো তথ্য
(নোটিশ, টিচার, রেজাল্ট ইত্যাদি) বদলাতে হলে কোন ফাইলে যেতে হবে, আর কোনো সমস্যা হলে প্রথমে কোথায়
খুঁজতে হবে।

> ⚠️ **সবচেয়ে গুরুত্বপূর্ণ কথা:** দিন-প্রতিদিনের কাজ — নোটিশ দেওয়া, রেজাল্ট দেওয়া, টিচার যোগ করা,
> ছবি আপলোড করা — এসবের জন্য **কোনো কোড বদলানোর দরকার নেই**। এই সবকিছু ওয়েবসাইটের
> **অ্যাডমিন প্যানেল** (`/admin/login` দিয়ে লগইন করে) থেকেই করা যায়। নিচের ফাইলগুলো শুধু তখনই লাগবে
> যখন ডিজাইন/ফিচার বদলানোর মতো কোডের কাজ করতে হবে।

## ১. সংক্ষেপে প্রজেক্টটা কী

- **পাবলিক ওয়েবসাইট** — যে কেউ দেখতে পারে: হোম পেজ, মাদ্রাসা পরিচিতি, শিক্ষকমণ্ডলী, রেজাল্ট খোঁজা,
  নোটিশ বোর্ড, গ্যালারি, যোগাযোগ, অভিযোগ ফর্ম।
- **অ্যাডমিন প্যানেল** — শুধু লগইন করা অ্যাডমিনের জন্য: সব তথ্য যোগ/সম্পাদনা/মোছা যায় এখান থেকে।
- **ডেটাবেজ** — সব তথ্য জমা থাকে **Supabase**-এ (ক্লাউডে)। ওয়েবসাইট আর ডেটাবেজ আলাদা, ওয়েবসাইট শুধু
  ডেটাবেজ থেকে তথ্য এনে দেখায়।
- **হোস্টিং** — ওয়েবসাইটের কোড থাকে **GitHub**-এ, আর সেখান থেকে **Vercel** সাইটটা ইন্টারনেটে লাইভ রাখে।

## ২. রুটিন কাজ কোথা থেকে করবেন (কোড লাগবে না)

| গ্যালারিতে ছবি/ভিডিও দেওয়া | অ্যাডমিন প্যানেল → **গ্যালারি** |
| অভিযোগ দেখা ও উত্তর দেওয়া | অ্যাডমিন প্যানেল → **অভিযোগ** |
| মাদ্রাসার ঠিকানা/ফোন/ইতিহাস বদলানো | অ্যাডমিন প্যানেল → **মাদ্রাসা তথ্য** |
| হোম পেজের ব্যানার ছবি/কথা বদলানো | অ্যাডমিন প্যানেল → **ওয়েবসাইট সেটিংস** |
| গোপনীয়তা নীতি / শর্তাবলী বদলানো | অ্যাডমিন প্যানেল → **Privacy Policy** / **Terms** |

এই পুরো টেবিলের কোনো কাজেই কোড বা GitHub-এ যাওয়ার দরকার নেই।

## ৪. `src/` ফোল্ডারের ভেতরে কী আছে

### ৪.১ শুরুর ফাইল

| ফাইল | কী করে |
|---|---|
| `src/main.tsx` | ওয়েবসাইট চালু হওয়ার প্রথম লাইন — `App.tsx`-কে স্ক্রিনে বসায় |
| `src/App.tsx` | কোন URL-এ কোন পেজ দেখাবে তার তালিকা (যেমন `/notices` → নোটিশ পেজ) |
| `src/index.css` | সাইটের **রঙ, ফন্ট, বাটনের স্টাইল, অ্যানিমেশন** — সব এখানে। সবুজ রঙ বদলাতে চাইলে এই ফাইলের শুরুর দিকে `--primary` লাইনটা বদলালেই পুরো সাইটে বদলে যায় |

### ৪.২ `src/lib/` — ছোট ছোট সহায়ক ফাইল

| ফাইল | কী করে |
|---|---|
| `src/lib/supabase.ts` | ডেটাবেজের সাথে সংযোগ তৈরি করে। "Remember Me" লগইন মনে রাখার ব্যবস্থাও এখানে |

| `src/lib/storage.ts` | ছবি আপলোড ও ইউনিক আইডি তৈরির সহায়ক ফাংশন |
| `src/lib/grade.ts` | রেজাল্টের নম্বর যোগ করে গ্রেড (A+, A, B...) বের করে |
| `src/lib/utils.ts` | ছোটখাটো সহায়ক ফাংশন (যেমন আজকের তারিখ ঠিকভাবে বের করা) |

### ৪.৩ `src/types/index.ts`

একটা ফাইল, যেখানে লেখা আছে একজন **টিচার**, একটা **রেজাল্ট**, একটা **নোটিশ** ইত্যাদির মধ্যে কী কী তথ্য
থাকবে (নাম, ছবি, তারিখ...)। নতুন কোনো তথ্য (যেমন টিচারের "Facebook ID") যোগ করতে চাইলে প্রথমে এই

## ৫. ডেটাবেজ (Supabase) — তথ্য কোথায় জমা থাকে

ওয়েবসাইটে যা দেখা যায় তার প্রতিটা অংশ Supabase-এর একটা করে টেবিলে জমা থাকে:

| টেবিলের নাম | কী জমা থাকে |
|---|---|
| `teachers` | শিক্ষকদের তথ্য |
| `classes` | ক্লাসের তালিকা |
| `subjects` | বিষয়ের তালিকা |
| `results` | ছাত্রদের রেজাল্ট |
| `notices` | নোটিশ |
| `gallery` | গ্যালারির ছবি/ভিডিও |
| `complaints` | অভিযোগ (এটা প্রাইভেট — শুধু অ্যাডমিন দেখতে পারে) |
| `madrasa_info` | মাদ্রাসার পরিচিতি/ইতিহাস/ঠিকানা (একটাই সারি) |
| `website_settings` | ব্যানার, রঙ, সোশ্যাল লিংক (একটাই সারি) |
| `pages_content` | গোপনীয়তা নীতি ও শর্তাবলীর লেখা (একটাই সারি) |

**Row Level Security (RLS)** নামের একটা নিরাপত্তা ব্যবস্থা ডেটাবেজে সেট করা আছে, যার মানে: কে পড়তে
পারবে আর কে লিখতে পারবে — এটা ডেটাবেজ নিজেই আটকায়, শুধু ওয়েবসাইটের কোডের উপর ভরসা করে না। তাই
কেউ যদি ওয়েবসাইটের নিরাপত্তা পাশ কাটিয়েও ডেটাবেজে সরাসরি ঢোকার চেষ্টা করে, RLS তাকে আটকে দেবে।

**ছবি/ফাইল** জমা থাকে Supabase Storage-এ, ৫টা আলাদা জায়গায় (bucket): `teachers`, `gallery`, `madrasa`,
`hero`, `notices`।

**`fix-complaint-search.sql`** — এই আলাদা ফাইলটা দিয়ে একটা বিশেষ নিরাপদ ব্যবস্থা বানানো হয়েছে, যাতে
সাধারণ ভিজিটর নিজের অভিযোগ ট্র্যাক করতে পারে, কিন্তু অন্য কারো অভিযোগ দেখতে না পারে। **এই SQL ফাইলটা
Supabase-এর SQL Editor-এ একবার Run করা না থাকলে "আমার অভিযোগ" অপশনটা কাজ করবে না।**

## ৬. `.env` ফাইল — সবচেয়ে স্পর্শকাতর ফাইল

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

এই দুটো লাইনে Supabase ডেটাবেজের ঠিকানা আর একটা চাবি (key) লেখা থাকে। **এই ফাইলটা না থাকলে বা ভুল
হলে পুরো ওয়েবসাইট অচল হয়ে যাবে** (কোনো তথ্যই দেখাবে না)। এটা কখনো কারো সাথে প্রকাশ্যে শেয়ার করা
উচিত না (যদিও এটা "anon key", যা পাবলিক ব্যবহারের জন্যই বানানো, তবু সতর্ক থাকা ভালো)। GitHub repo
যদি Public থাকে, সেটাকে Private করে রাখা উচিত।

## ৮. আপডেট কীভাবে দেওয়া হয় (ডেভেলপারের জন্য)

1. নতুন কোড/ফিক্স একটা `.zip` ফাইলে প্যাক করে GitHub repo-তে আপলোড করা হয়।

   লাইভ করে দেয়।
